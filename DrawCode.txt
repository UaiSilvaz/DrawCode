PADRÃO DE COMPONENTES - SERVER vs CLIENT:

• Server Components (padrão):
  - layout.tsx
  - page.tsx (root)
  - metadata ativa (SEO com Metadata API)

• Client Components ('use client'):
  - ClientLayout.tsx - wrapper para interatividade global
  - Topo.tsx - estado (modal login), animações GSAP
  - TargetCursor.tsx - event listeners de mouse, refs
  - ConditionalTargetCursor.tsx - lógica condicional de render
  - Silk.tsx - Three.js Canvas rendering
  - WebBuilder.jsx - GrapesJS initialization
  - Componentes com estado: useState, useEffect, useContext

• Dynamic Imports:
  - Silk importado dinamicamente em Topo.tsx
  - Sintaxe: dynamic(() => import("./Silk"), { ssr: true })
  - SSR habilitado para SEO

PATH ALIAS:
  • @/* → ./src/*
  • Definido em tsconfig.json "paths"
  • Permite imports limpos: import Topo from "@/components/Topo"

PONTOS DE ENTRADA:
  • Layout root: src/app/layout.tsx
  • Página inicial: src/app/page.tsx
  • Routes: /grape, /login
  • Metadata: Definida em layout.tsx (título, descrição, ícones, manifest)

7. SEGURANÇA E ESTABILIDADE
================================================================================

NÍVEL DE ESTABILIDADE DAS DEPENDÊNCIAS:

✅ ESTÁVEIS (Produção-ready):
  • Next.js 16.1.1 (LTS)
  • React 19.2.3 (versão mais recente, estável)
  • TypeScript 5 (estável)
  • Tailwind CSS v4 (latest)
  • GSAP 3.14.2 (industria-padrão)
  • Three.js 0.182.0 (estável)
  • @react-three/fiber 9.5.0 (bem mantido)
  • MUI 7.3.7 (estável)
  • HeroUI 2.8.7 (estável)
  • ESLint 9 (atual)

⚠️ AVISOS E POTENCIAIS RISCOS:

  1. GrapesJS (v0.22.14):
     - Em desenvolvimento ativo mas com menos tração que alternativas
     - Bundle size relativamente grande
     - Sem tree-shaking agressivo

  2. Dependência Obsoleta:
     - backbone-undo v0.2.6 (npm warn deprecated)
     - Não mais mantido
     - Presente como sub-dependência do GrapesJS

  3. Vulnerabilidade de Segurança:
     - 1 HIGH severity vulnerability encontrada no audit
     - Recomendação: npm audit fix (com cuidado)
     - Alternativa forçada: npm audit fix --force (pode quebrar backbone-undo)

  4. Conflito de Estilos Potencial:
     - Dual styling: Tailwind + Emotion + MUI
     - Pode gerar conflitos de CSS specificity
     - Recomendação: Estabelecer convenção de uso

  5. Bundle Size:
     - Three.js + @react-three/fiber = ~400-500KB
     - GrapesJS = ~200-300KB
     - Emotion + MUI = adicional
     - Total: ~800KB+ (não minificado)
     - Recomendação: Code splitting e lazy loading

COMPATIBILIDADE ENTRE BIBLIOTECAS:

✓ Totalmente compatível:
  • Next.js 16 + React 19
  • React 19 + @react-three/fiber 9.5
  • Tailwind v4 + PostCSS
  • TypeScript 5 + ESLint 9

⚠️ Atenção especial:
  • Emotion + MUI + Tailwind (3 sistemas de estilo)
  • GrapesJS + Next.js (GrapesJS é jQuery-based, não React-nativo)
  • Dynamic imports necessários para Three.js no SSR
